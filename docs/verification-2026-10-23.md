# 2026-10-23：可信预览与现场体验增量

基准为 Draft PR #1 的 `a68bff5f2a91cd1817cb2d300ee2c18bc50340b9`。本记录只描述这一增量，不把历史自动检查或桌面截图当作手机交付和真实农业效果证据。旧验证日志保留在 [verification.md](verification.md)，当前业务含义以 [API 契约](api-contract.md) 为准。

## 改变了什么

- 保存输入、探索分析和正式监测资格分离。所有用户数据分析均为 preview、monitoring_eligible=false、risk_id=null；完整摘要和质量声明仍不等于独立来源核实。显式开发模拟可演示候选，但不是正式监测。
- 报告收到只完成巡田执行。六种现场标签均为未裁定、待复核；关联候选未解决，不因“正常”或“暂不能判断”自动退出待处理。尚未增加专业裁定、排除或结案入口。
- 关联复查保留源报告并继承同一候选；普通巡田与复查共享事件待办约束，无候选报告链也不能重复分叉出待办。历史空事件链接按来源链读取，不批量重写原库或旧回执。
- 光学与天气各自计算时效；天气不替光学续新。分析、单条/整批观测及关联复查的前端回执校验与新的状态含义对齐。
- 管理总览把待巡田和待复核置前，目录/地图退为按需展开；记录和任务高级筛选折叠。现场编辑/核对改为全高任务面板，固定操作区，核心现场内容在前，完整身份仍可核对。

## 独立集成检查

使用 Python 3.12、Node 24，在既有云代码副本运行以下命令；测试数据库均新建于临时目录，没有使用真实田块或原应用数据库。

```sh
bash scripts/check.sh
python scripts/http-smoke.py
sha256sum -c SOURCE_MANIFEST.sha256
git diff --check
```

最终源码回归结果：后端 123 项通过；前端 439 项通过，零失败、取消或跳过；严格 TypeScript 检查与 Vite 生产构建通过；隔离 HTTP smoke 通过。该次 HTTP 检查读取重建资产 `index-DiYsy8Mb.js` 与 `index-BZXvptsL.css`。源码摘要校验与 diff 空白检查在提交前复核。

HTTP smoke 启动自己的随机本机端口及临时数据库，只终止它自己启动的服务；不会接管既有浏览器会话或数据库。

覆盖包括：

- 未核实/仅声明数据不得生成正式候选，空/过期/未触发/候选式预览以及 fixture 分离。
- 六种报告标签、无候选报告、旧 verified 只读投影、重复分析保留待复核、历史原始字节和回执不被读取修改。
- 多代来源链、损坏/循环关联拒绝、同事件普通与复查并发竞争、无候选链重复待办、幂等原始回执。
- 实际 HTTP 读取和写入响应交由生产前端回执/读取验证器核对；整批冲突原子回滚、历史光学 blocked、来源/内容/模式错误不误报。
- 现场核对、草稿/照片版本保护、未知响应、迟到响应、重复点击、返回修改与筛选保持。DOM 与 IndexedDB 为受控测试替身，不是浏览器/设备验证。

独立审查还修复三类集成问题：首次读取失败不能显示零待办；旧版空候选链接复查修改计划时，新回执必须与当前派生身份一致，已存在的历史回执仍原样回放；无候选报告链的祖先/后代与历史分支应指向既有待办，不引导重复创建。链路缺失、重复身份、跨地块或循环时不猜测关联；确认文案与候选 assigned、事件未解决的语义保持一致。
