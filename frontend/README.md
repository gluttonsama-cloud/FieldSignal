# FieldSignal 前端 V0

中文、本地优先的油菜监测工作台。两个入口：

- `/admin`：地块目录 / 区域筛选、边界示意、观测时序与质量、来源详情、统计分析、候选派单、核查记录；独立「数据接入」页。
- `/field`：手机优先的巡田 / 地块 / 记录；核查草稿、照片、农事登记。

这是浏览器原型，不是原生 Android 应用。默认空数据；只有后端显式启用 fixture 时显示“加载开发模拟数据”，模拟地块与相关任务、记录始终标明来源。

## 运行

推荐 Node.js 24。项目已锁定官方 npm 包版本，`npm ci` 使用 package-lock.json。

```sh
npm ci
npm run build
```

生产构建输出 `dist/`，由项目 FastAPI 本地服务直接提供 `/admin`、`/field` 及静态资源。开发时，后端在 `127.0.0.1:8000`，另运行：

```sh
npm run dev
```

Vite 绑定 `127.0.0.1:5173`，代理 `/api` 至本地 API。无需 CDN、外部字体、在线地图、地理编码或遥测。

## 数据接入与公开样本

- 管理导航的「数据接入」独立于地块总览。只读取本地能力清单，不把目录可读或历史样本验证显示为实时在线；SAR 的授权 / 费用门槛明确保留。
- 用户点击「导入公开样本到本地」才向本地 API 提交。启动 / 渲染不会自动 POST；导入期间禁用重复点击与刷新，完成后重新读取列表，同一版本复用原记录。网络失败隐藏旧状态，并区分“导入结果未确认”和“已确认但刷新失败”。
- 随工程提供的沙洋附近公开任意 320 m 方窗不是已知油菜田，也不是用户地块。公开样本存入独立样本库，不进入地块选择、统计、分析、巡田或人工核查流程；与开发模拟 fixture 明确区分。
- 展示原始采集（2025-04-28）、证据获取（2026-10-15）及本次本地导入时间，统一明确标注 UTC。4 条历史记录显示过期，单次光学观测不形成地块时序分析，保留 insufficient_data。
- S2 B04/B08 10 m、SCL 20 m，显示窗口有效像元与实际 SCL 8/9/10 云比例；不会将 1 − 有效比例当云量。POWER 0.5° × 0.625° 粗网格按 UTC 日，显示 °C / mm/day，不当作地块测站或预报。
- 来源记录、空间支持、时间支持、许可 / 署名、资产及样本包 SHA-256 可展开核对。外部链接仅允许不含凭据的 HTTPS，转义所有 API 文本，不主动加载链接内容。
- 旧版真实地块 JSON 导入仍保留；其来源、质量与空间支持是提交者声明，尚未独立核验。未提供字段显示未知，不补零，也不推断授权或真实性。

## 草稿与照片的真实边界

- 已打开页面可在断连时编辑现场核查。IndexedDB 保存文字、照片 Blob、已上传照片 ID、待删除照片队列及一次提交的 UUID。
- 已保存草稿可在本机存储暂时无法写入时打开查看；未编辑返回不重写。编辑或提交仍需确认持久化，不能把内存中的新内容当成已保存。
- 每次修改均排队写入 IndexedDB；状态仅在最新排队事务确认后显示“已保存到本机”。保存失败可点“重试保存到本机”；提交、保存返回及 Escape 也先确认本机持久化。失败时保留当前页的备注和照片，不能宣称已写盘。版本冲突仍保留另一页的新草稿，不自动覆盖。
- 必须由用户手动提交 / 重试；没有 service worker、后台同步、推送或离线重开页面缓存。
- 浏览器草稿仅属于当前浏览器及来源地址。`127.0.0.1:5173` 和 `127.0.0.1:8000` 的草稿互不共享。清除网站存储、隐私浏览或更换设备可能丢失草稿。
- 图片仅上传至本地服务；核查成功且响应核验通过后才清理相同版本的草稿。上传或提交失败会保留草稿和照片。服务端用提交 UUID / 照片哈希处理重试。
- 删除已上传但尚未提交的照片会保留待删除队列；重试时先在服务端删除，再上传替代照片。
- revision + 提交 UUID 的 CAS 保护跨标签页写入和清理。旧页不能覆盖或删除另一页的新草稿，冲突时显示提示。
- 农事记录目前是在线表单，不支持离线草稿。地块/农事保存使用当前表单内的内容绑定请求编号，原样重试核对原记录；修改内容会生成新编号，改回已提交内容复用旧编号。关闭、重开或刷新后不保留编号，修改或重开前需先检查原记录是否已保存。

## 观测与地图表达

- 地图是本地 SVG 地块边界示意，没有外部底图；面积为服务端近似估算，不用于测绘或精确空间分析。
- 无数据、过期、质量受限分别表达。“有可用观测”及“未触发候选”均不代表地块健康。
- NDVI 连线要求质量合格、有效比例至少 0.6、S2 云量存在且不高于 0.4；相邻间隔不超过 14 天，且 source / collection / processing_version 相同。缺口不插值。
- 人工核查标签是用户报告，不是确诊结果。
