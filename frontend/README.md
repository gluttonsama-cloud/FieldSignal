# FieldSignal 前端 V0

中文、本地优先的油菜监测工作台。两个入口：

- `/admin`：地块目录 / 区域筛选、边界示意、观测时序与质量、来源详情、统计分析、候选派单、核查记录；独立「数据接入」页。
- `/field`：手机优先的巡田 / 地块 / 记录；核查草稿、照片、农事登记。

这是浏览器原型，不是原生 Android 应用。默认空数据；只有后端显式启用 fixture 时显示“加载开发模拟数据”，模拟地块与相关任务、记录始终标明来源。

## 当前体验与状态边界（2026-10-23）

- 管理总览优先呈现待巡田与待复核，存量统计缩为摘要，地块目录与边界示意按需展开；读取失败且没有有效快照时不显示“没有待办”。记录页不再复制全局统计或录入地块主按钮。
- 记录关键词查找为默认入口，标签/日期/地块条件收进“更多筛选”；任务筛选同样默认折叠。有已应用条件时仍展开并显示范围，不悄悄清空筛选或本机草稿。
- 现场编辑与提交核对使用全高任务页、一个内容滚动区与固定底部操作；现象、照片、备注优先，观察时间与完整技术身份可展开核对。保存、取消、返回修改和最终确认仍遵守原草稿版本与会话隔离规则。
- 用户导入的来源/质量/摘要只是声明，分析只能预览，不产生正式监测候选；模拟演示与历史探索候选明确标识。光学与天气时效独立，光学 available 不代表有充分历史或正式资格。
- 所有现场报告均为“已提交 · 待复核”，完成的是这次巡田，不是事件结案。当前没有专业裁定或问题解决入口；复查仍保留同一事件和来源报告。
- 分析、单条与整批观测的回执须与实际发送目标、方法/内容及模式一致。错误回执不触发成功提示；读取结构与业务资格是两层检查，不相互替代。

本轮只部分查看了桌面浏览器截图，未完成照片选择到最终提交的浏览器闭环、窄屏/手机真机或弱网验收。详见[本轮验证记录](../docs/verification-2026-10-23.md)；下文历史记录不代表当前版本已完成这些验收。

## 运行

推荐 Node.js 24。项目已锁定官方 npm 包版本，`npm ci` 使用 package-lock.json。

```sh
npm ci
npm run build
```

生产构建输出 `dist/`，由项目 FastAPI 本地服务直接提供 `/admin`、`/field` 及静态资源。开发时，后端在 `127.0.0.1:8000`，另运行：

```sh
npm run dev
```

Vite 绑定 `127.0.0.1:5173`，代理 `/api` 至本地 API。无需 CDN、外部字体、在线地图、地理编码或遥测。

## 数据接入与公开样本

- 管理导航的「数据接入」独立于地块总览。只读取本地能力清单，不把目录可读或历史样本验证显示为实时在线；SAR 的授权 / 费用门槛明确保留。
- 用户点击「导入公开样本到本地」才向本地 API 提交。启动 / 渲染不会自动 POST；导入期间禁用重复点击与刷新，完成后重新读取列表，同一版本复用原记录。网络失败隐藏旧状态，并区分“导入结果未确认”和“已确认但刷新失败”。
- 随工程提供的沙洋附近公开任意 320 m 方窗不是已知油菜田，也不是用户地块。公开样本存入独立样本库，不进入地块选择、统计、分析、巡田或人工核查流程；与开发模拟 fixture 明确区分。
- 展示原始采集（2025-04-28）、证据获取（2026-10-15）及本次本地导入时间，统一明确标注 UTC。4 条历史记录显示过期，单次光学观测不形成地块时序分析，保留 insufficient_data。
- S2 B04/B08 10 m、SCL 20 m，显示窗口有效像元与实际 SCL 8/9/10 云比例；不会将 1 − 有效比例当云量。POWER 0.5° × 0.625° 粗网格按 UTC 日，显示 °C / mm/day，不当作地块测站或预报。
- 来源记录、空间支持、时间支持、许可 / 署名、资产及样本包 SHA-256 可展开核对。外部链接仅允许不含凭据的 HTTPS，转义所有 API 文本，不主动加载链接内容。
- 同一地块规范化 JSON 可选单条，或先「核对整批」再明确确认（最多 500 条、1 MiB）。只读核对展示固定地块、逐条来源/质量与批次限制；不自动上传或分析。服务全批原子校验，完全一致记录复用，内容冲突整批拒绝；成功逐条显示新增/已有回执。结果不明保留原批次和手动重试编号，已确认回执不因列表刷新失败丢失。
- 真实地块 JSON 文件先读入当前表单再由用户提交；新选择或手动修改会取消迟到读取，文件未读完不能提交旧内容。提交期间锁定该表单输入，失败后保留内容供检查。
- 旧版真实地块 JSON 导入仍保留；其来源、质量与空间支持是提交者声明，尚未独立核验。未提供字段显示未知，不补零，也不推断授权或真实性。

## 待巡田任务筛选与身份

- 管理端待巡田区与田间助手可按计划日期、执行人标签、地块组合筛选，显示匹配数 / 当前已加载总数；原有按计划日、创建时间与 ID 排序不变。已过计划日不是严重程度。
- 筛选只保存在当前页面内存，不读写存储、不请求服务、不改变选中地块、异常候选、全局统计或本机草稿。执行人是精确本地标签，不推断账号或「我的任务」。缺失/无效计划日仅在全部日期下显示。
- 刷新后已不在选项中的标签或地块仍作为明确的旧筛选保留，不会悄悄扩大范围；无匹配与没有任务分别显示。可一键清除。新任务创建确认且原表单仍有效时清除旧筛选；失败、迟到响应、更新后的筛选和计划调整不重置。
- 同名地块任务和本机草稿显示地块 ID、完整任务 ID、种植季/未保存状态；草稿名称和季节来自其保存快照。身份文本转义并允许换行，不接入地图、账号或通知。

## 查找与下载已保存核查

- 管理端现场反馈和田间助手记录页可组合筛选备注/地块名称/完整记录身份关键词、用户报告标签与观察日期。管理端另可选地块；田间助手沿用当前地块，不改变农事记录或本机草稿。关键词是忽略大小写的字面包含检索，不推断语义或病因。
- 修改输入后须点「应用筛选」；尚未应用的输入与当前结果明确区分。刷新、失败、切换页面保留页面内筛选，不读写持久存储。过期选项保留原值，不悄悄扩大范围；无效/倒置日期不显示或导出任何记录。
- 日期按设备当前时区的观察日筛选，不按保存日；晚补的旧观察也可找回。最近保存优先排序不变，卡片显示完整地块、巡田任务和核查 ID。当前表单核查确认成功并跳到记录时清除旧筛选，确保新记录可见；失败、迟到响应和提交期间的新筛选操作不清除。
- 「下载当前结果 CSV」与卡片使用相同的已应用条件和顺序，注明范围、条件与已加载完整性；不代表服务端全部数据。原始 API 时间保留，公式防护不变。只包含核查文字元数据，不含本机草稿、农事或照片文件，不能替代服务端备份。
- 农事历史另有「下载已读取农事 CSV」：仅在当前地块农事成功读取且非空时提供，沿用可见顺序，不受核查筛选影响。显示地块全名 / ID、条数、读取时间与快照限制；保留农事日期、API 保存时间、类型代码和原始备注。地块切换或读取失败后不能误下载旧范围。
- 两类下载均由显式点击生成本地 UTF-8 CSV，不请求服务、不写入草稿、不自动上传，不包含照片或原始数据文件。公式样文本加可见「文本：」前缀。农事登记仅供对照，不代表措施效果、异常成因或诊断，CSV 不等同于无损数据库备份。

## 草稿与照片的真实边界

- 已保存核查可显式「安排复查」：先核对原报告与固定地块，再填写计划日、执行人标签和提示；不是自动通知或诊断。复查任务保留来源核查 ID 并继承候选链接，原报告和照片不变；同一事件的普通巡田/复查，或无候选的同一报告链，最多一个待完成任务。完成后可再明确安排，事件仍未解决。
- 待办与后续核查区分复查、自主巡田和候选核查。可查看上次已加载核查及照片；来源未读取或关系不一致时明确提示，不替换成当前地块/最近候选。调整计划保留来源，现场观察时间不得早于上次观察。请求结果未知时保留原表单和编号，既有创建回执不冒充当前待办状态。

- 现场核查先点「核对并提交」查看只读核对页，再点「确认提交并完成巡田」。核对页显示完整地块与任务 ID、种植季、观察时间、判断、完整备注、照片顺序和未附照片状态；不新增服务请求、不自动上传。返回修改保留草稿与照片。
- 最后确认只接受当前页面实际核对过的内容。修改、关闭、切换任务或新会话会使旧确认失效；保存失败/未知提交结果回到原草稿，重新核对后才能手动重试。成功后完成该巡田，当前版本不可修改已提交记录；所有标签仍为待复核的用户报告，不代表确诊、排除或事件解决。

- 已打开页面可在断连时编辑现场核查。IndexedDB 保存文字、照片 Blob、已上传照片 ID、待删除照片队列及一次提交的 UUID。
- 已保存草稿可在本机存储暂时无法写入时打开查看；未编辑返回不重写。编辑或提交仍需确认持久化，不能把内存中的新内容当成已保存。
- 服务返回成功状态但读取结构异常时，保留上次完整可用的核心页面数据并明确报错，不替换成空列表，不阻断本机草稿与手动刷新。观测/分析、农事各自显示局部读取问题；恢复后可显式刷新。此保护只核对渲染所需结构，不代表观测来源或业务内容已获独立核验。
- 每次修改均排队写入 IndexedDB；状态仅在最新排队事务确认后显示“已保存到本机”。保存失败可点“重试保存到本机”；提交、保存返回及 Escape 也先确认本机持久化。失败时保留当前页的备注和照片，不能宣称已写盘。版本冲突仍保留另一页的新草稿，不自动覆盖。
- 必须由用户手动提交 / 重试；没有 service worker、后台同步、推送或离线重开页面缓存。
- 浏览器草稿仅属于当前浏览器及来源地址。`127.0.0.1:5173` 和 `127.0.0.1:8000` 的草稿互不共享。清除网站存储、隐私浏览或更换设备可能丢失草稿。
- 图片仅上传至本地服务；核查成功且响应核验通过后才清理相同版本的草稿。上传或提交失败会保留草稿和照片。服务端用提交 UUID / 照片哈希处理重试。
- 核查回执须与本次发送快照的任务、地块、提交 UUID、观察时刻、判断、归一后的备注及有序照片 ID 一致；损坏/错配回包不会清理草稿或误报任务完成。照片回执另核对任务和处理元数据，但不声称核验图片字节（服务未返回摘要）。已确认的照片 ID 保留，最终回执未知时手动重试相同报告不重复上传这些照片。
- 清理使用发送时的草稿修订版本，而非请求期间可能变化的当前对象；新修订继续受 CAS 保护。合法时区与微秒归一、Unicode White_Space 处理及已确认照片的幂等回放均保留。
- 删除已上传但尚未提交的照片会保留待删除队列；重试时先在服务端删除，再上传替代照片。
- 两张原图经服务端处理后若对应同一照片，最终核查不会发送；提示对应序号并要求只保留一张，再核对后手动提交。不静默合并或减少已核对的照片。移除一个重复项只移除本机该项；最后一个引用移除后才排入服务端删除队列。
- 提交前会检查旧删除队列：仍被保留照片引用的 ID 不删除，重复删除 ID 只保留一次；先确认本机修复保存，再执行任何删除或上传。保存失败或跨页版本冲突时停止网络操作，保留原始照片，允许明确手动重试。
- revision + 提交 UUID 的 CAS 保护跨标签页写入和清理。旧页不能覆盖或删除另一页的新草稿，冲突时显示提示。
- 农事记录目前是在线表单，不支持离线草稿。地块/农事保存使用当前表单内的内容绑定请求编号，原样重试核对原记录；修改内容会生成新编号，改回已提交内容复用旧编号。关闭、重开或刷新后不保留编号，修改或重开前需先检查原记录是否已保存。
- 地块、任务、计划和农事仅在回执与本次提交匹配后确认保存；2xx 的空/损坏/HTML 响应不会被当作成功。结果未确认时保留当前表单、输入与原请求编号，等待用户手动原样重试。提交中输入暂时锁定；关闭后不能保证恢复原编号。

## 观测与地图表达

- 地图是本地 SVG 地块边界示意，没有外部底图；面积为服务端近似估算，不用于测绘或精确空间分析。
- 无数据、过期、质量受限分别表达。“有可用观测”及“未触发候选”均不代表地块健康。
- NDVI 连线要求质量合格、有效比例至少 0.6、S2 云量存在且不高于 0.4；相邻间隔不超过 14 天，且 source / collection / processing_version 相同。缺口不插值。
- 人工核查标签是用户报告，不是确诊结果。
