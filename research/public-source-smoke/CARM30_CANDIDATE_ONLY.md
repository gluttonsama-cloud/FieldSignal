# CARM30：仅作历史油菜候选分布

核验日期：2026-10-15 UTC。此次只核对原始论文与作者数据发布页；没有下载全国栅格，也没有把任意像元作为用户地块或异常标签。

- 权威来源：Liu et al., Scientific Data 11, 356 (2024)，[原论文](https://www.nature.com/articles/s41597-024-03188-1)，DOI 10.1038/s41597-024-03188-1。
- 作者发布数据：[Mendeley Data v1](https://data.mendeley.com/datasets/hxhkphgmtt/1)，DOI 10.17632/hxhkphgmtt.1；发布者 Wenbin Liu、Hongyan Zhang，2023-08-24。这里独立核对了**数据**的许可为 CC BY 4.0，没有将论文许可偷换为数据许可。
- 数据声明：2000–2022年逐年、30m、GeoTIFF、WGS1984 UTM Zone48N（对应EPSG:32648；真正下载后仍需检查GeoTIFF）。论文 Data Records 明确分类码：0=非油菜、1=油菜。
- 可用角色：为历史同年份的研究选样、候选区和分层抽样提供先验；引用作者/DOI/版本，标注修改。对2025/2026季节只能作为**过时的历史候选信息**，不能确认当前作物。
- 边界：分类结果存在误分，30m混合像元难以精确界定小地块；罗田丘陵碎片化更需核验。不能把地图矢量化边界当土地确权/农户边界，不能复制论文精度为本项目精度。它也不是病害/冻害/积水事件真值，不能承担监督异常训练标签或独立外测真值。
- 与本次S2样本差异：CARM30声明UTM48N，沙洋S2实测为UTM49N；不能直接拼接像元索引，需明确重投影和最近邻分类栅格重采样。没有实际读取CARM30资产，因此其 nodata、波段字段、2022文件可下载性及小窗结果仍待核验。
- 作者还提供[代码仓库](https://github.com/liuwenbinwhu/China-annual-rapeseed-maps30)，但本次没有将其代码引入核心管线，也没有把GitHub可见当成代码再利用许可已核实。

“T49RFQ”也由本次 Earth Search 实测目录确认有2025-03-12场景；AOI横跨/邻近tile重叠，FP和FQ都可能返回。tile编号不是地块ID，不应硬编码成整个沙洋唯一tile。本次实际读窗使用49RFP。
